# Heng Menghong Portfolio

React + TypeScript + Tailwind CSS portfolio generated from the CV in the parent
folder.

## Project Structure

- `src/App.tsx` - one-page portfolio sections and CV data
- `src/components/ui` - shadcn-style UI components
- `src/components/ui/glassmorphism-portfolio-block-shadcnui.tsx` - main hero/profile block
- `src/lib/utils.ts` - className utility used by UI components
- `public/images/Heng_Menghong.png` - local profile image

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## GitHub Pages

The Vite base path is configured as `/Portfolio/`, so deploy this folder to a
GitHub repository named `Portfolio` under `menghong-heng` to use:

```text
https://menghong-heng.github.io/Portfolio/
```
